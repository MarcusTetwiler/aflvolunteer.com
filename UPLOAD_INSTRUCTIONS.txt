AFL FLIGHT SIMULATOR V2 — GITHUB WEB UPLOAD

1. Unzip AFL_FLIGHT_SIMULATOR_V2.zip on your computer.
2. Open the extracted folder.
3. In the GitHub repository, choose Add file > Upload files.
4. Drag BOTH the src folder and public folder onto the upload page.
5. Confirm paths begin exactly with src/ and public/.
6. Commit directly to main and allow Vercel to redeploy.
