This ZIP is a cumulative OVERLAY, not a replacement repository.
It contains only files that are new or changed for this batch.

UPLOAD
------
1. Unzip this package.
2. Open the aflvolunteer.com repository on GitHub and choose Add file -> Upload files.
3. Upload the contents of these folders while preserving their paths:
      src/
      public/
      scripts/
   Existing repository files that are not included here should remain untouched.
4. Commit to main (or a review branch first, if preferred).
5. Let Vercel deploy the commit.

DO NOT upload the _REFERENCE folder to production unless you want the visual
mockup kept in the repository. It is included only as a design reference.

POST-DEPLOY SMOKE TEST
----------------------
- Open the site at 320–430px wide and confirm the sample email form does not clip.
- Confirm the new Enter the World landing appears before The Front.
- Confirm Elena's map is framed on eastern Poland / Ukraine / Baltics / Moldova / Romania.
- Finish the sample and confirm the page advances naturally instead of jumping backward.
- Enter Elena's Bench, then Save & Return; confirm the exact prior scroll position is restored.
- Tap GEAR in the top navigation; it should open AFL Field Supply directly.
- In Field Supply, filter/search products, open a product, and submit a product waitlist email.
- Confirm every product is OUT OF STOCK and marked CONCEPT / IN DEVELOPMENT.
- Confirm Contribute reads “This world is not invented.” and both glossary + real-world action paths work.
