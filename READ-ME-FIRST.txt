STEP 2 — THE .gitignore FILE  (please don't skip)
=============================================================================
There is a file called ".gitignore" in the unzipped folder. It starts with a
dot, so macOS Finder and Windows Explorer HIDE IT BY DEFAULT and your drag
will probably miss it.

Easiest reliable way — create it directly on GitHub:
  1. Add file -> Create new file
  2. Name it exactly:  .gitignore
  3. Paste this in:

# Dependencies
node_modules/

# Build output
dist/
.vite/

# Environment — never commit Upstash/Beehiiv credentials
.env
.env.*
!.env.example

# Editor / OS noise
.DS_Store
*.swp
.idea/
.vscode/

# Private permission screenshots (DMs) — keep local, back up elsewhere
permissions/*
!permissions/README.md

# QA screenshot output
qa-shots/

  4. Commit.

Why it matters: this repo has never had a .gitignore. Without it, anyone who
clones the repo and runs "npm install" will try to commit ~4,300 dependency
files on their next commit. It costs nothing now and saves a mess later.
