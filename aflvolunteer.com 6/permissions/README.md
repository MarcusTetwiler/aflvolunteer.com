# Permission records

Screenshots of each builder's written yes, one file per build, named to match
the entry `id` in `src/data/buildWall.js` (e.g. `kitchen-table-quad.png`).

Keep these. If a builder ever changes their mind or a third party questions
whether you had the right to publish, this folder is the answer. It is
git-ignored so private DMs aren't pushed to a public repo — back it up somewhere
else (Drive, Dropbox) rather than relying on this folder alone.

**The rule:** no screenshot, no entry. `PUBLISHABLE_BUILDS` will refuse to render
anything without `permission.granted === true`, but that flag is only honest if
you actually have the receipt.
